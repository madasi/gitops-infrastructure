# 2026-11-09

## 🎯 Focus / Goals
* Establish a local, Git-backed daily journaling workflow for the homelab portfolio using Obsidian to document troubleshooting and architectural decisions.
* Lock down Proxmox and LXC container templates with strict zero-trust SSH policies.
* Achieve true GitOps idempotency for Ansible secrets management using SOPS.
* Deploy and configure a local DNS server (Technitium) for the homelab.

## 🛠️ Changes & Automation
* **Proxmox/Nodes:** 
    * Hardened `pve-dell01` SSH configuration (`PermitRootLogin no`, `PasswordAuthentication no`, `KbdInteractiveAuthentication no`).
* **Ansible/Tofu:** 
    * Created `bootstrap-lxc.yaml` to automate baseline container security (disabling password logins, creating unprivileged `ansible` user with explicit, password-protected sudoers drop-in).
    * Configured `automation/ansible/ansible.cfg` to set the default inventory and automatically decrypt SOPS variables in the background using `vars_plugins_enabled = host_group_vars,community.sops.sops`.
* **Secrets/SOPS:** 
    * Relocated `secrets.sops.yaml` to `group_vars/all/` for seamless auto-loading across all playbooks, eliminating manual `load_vars` tasks.
    * Generated and encrypted a scoped API token for DNS automation.
* **Services/DNS:** 
    * Provisioned `dns-primary` (192.168.1.53) via OpenTofu and bootstrapped via Ansible.
    * Installed Technitium DNS and secured the default admin account.
    * Created a dedicated `ansible-svc` service account in Technitium with explicit Least Privilege permissions (Zones and Settings only) for API automation.
* **Git/Repo:** 
    * Initialized `docs/journal/` and `docs/templates/` directories.
    * Added `.obsidian/workspace.json` and `.obsidian/workspace-mobile.json` to `.gitignore` to prevent syncing local UI state.
    * Created standardized daily stand-up template (`docs/templates/daily.md`).
    
## 🚧 Blockers & Troubleshooting
* **Ansible SOPS Decryption:** The SOPS plugin failed to decrypt `ansible_become_pass` when declared in `vars_plugins` because it bypassed Ansible's native variable loader. *Resolution:* Explicitly added `host_group_vars` alongside `community.sops.sops` in `ansible.cfg`.
* **Technitium API Token Generation:** Unable to generate service account tokens from the global admin dashboard due to undocumented UI/security changes. *Resolution:* Authenticated directly as `ansible-svc` in an incognito window to mint the token from the user profile dropdown.
* **WSL File Watcher Bug:** Attempting to open the WSL repository path (`\\wsl.localhost\archlinux\...`) from Windows Obsidian threw an `EISDIR` error due to filesystem watching incompatibilities. Pivoted to running the Linux native Obsidian app via WSLg.
* **WSL Memory Exhaustion (OOM):** Compiling `paru` from the AUR using `makepkg` spawned too many parallel Rust jobs, exceeding WSL's memory limits and silently killing the process.
* **Corrupted Rust Toolchain:** The OOM kill interrupted a critical write, corrupting the Cargo cache and the system `rust` package (truncating `librustc_driver.so` and causing a segmentation fault in `ldconfig`). 
    * *Resolution:* Removed the broken `rust` package (`pacman -Rns rust`), cleared `~/.cargo/`, rebuilt the linker cache (`sudo ldconfig`), and installed the pre-compiled `paru-bin` package instead.
* **Missing Emojis:** Native WSL Obsidian failed to render Unicode emojis. Fixed by installing `noto-fonts-emoji`.

## 📝 Decisions (ADRs)
* **Secret Management:** Decided to use `ansible.cfg` and `group_vars/all/` to silently decrypt SOPS files in the background, keeping playbooks DRY and adhering to strict GitOps standards.
* **API Security:** Decided against using the global admin account for DNS automation. Provisioned an isolated `ansible-svc` account to enforce the Principle of Least Privilege.
* **DNS Architecture:** Decided to scrap the apex `madasi.com` internal zone to avoid split-brain DNS mirroring overhead. Will migrate to a dedicated internal namespace (e.g., `int.madasi.com`).
* **Tooling:** Elected to use Obsidian over LogSeq for the project journal to maintain strict, standard Markdown compatibility for embedding YAML/code blocks. Running Obsidian natively inside the Arch WSL container to ensure seamless file watching.
